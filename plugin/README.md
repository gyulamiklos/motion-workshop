# motion-workshop plugin

Három skill: `motion-film`, `motion-explainer` (benne a fejlesztői összefoglaló), `motion-breakdown`. Mit tudnak és hogyan kell beállítani:
a repó gyökerében lévő [README.md](../README.md). A skillek a műhely klónjából futtatják az eszközöket
(`$MOTION_WORKSHOP`, vagy az aktuális repó, ha az a műhely).
