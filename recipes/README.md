# Recipes

Motion techniques learned from reference videos (`motion-breakdown` skill). One folder per technique:
`card.md` (what it is, measured timings, parameters, pitfalls) and `<name>.html` (a HyperFrames block).
The reference videos themselves stay in `research/` and are never committed.

`_principles.md` is the line-3D visual language (topic-free rules with measured numbers); `line3d/` is the Three.js kit that builds it, with one card per element.
